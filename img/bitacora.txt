#Justificaciones

~Fecha del Alquiler: Campo de Fecha (input type="date")

• Justificación: Soluciona el error de fechas equivocadas de WhatsApp al desplegar un calendario visual interactivo. Elimina por completo las confusiones de formato o de digitación, asegurando que el cliente reserve exactamente el día correcto.

~Tipo de Bicicleta y Planes: Listas Desplegables (<select>)

• Justificación: Resuelve el problema de bicicletas no disponibles al limitar las opciones del usuario únicamente al stock real del negocio es decirUrbana, Montaña, Eléctrica. Al no permitir texto libre, el cliente no puede inventar opciones inexistentes.

3. Datos Obligatorios: Atributo required en los campos clave

• Justificación: Elimina de raíz los datos incompletos, bloquea físicamente el envío del formulario mediante el método POST si falta algún campo vital como el celular o documento, forzando al navegador a avisar al usuario antes de procesar la reserva.


#pruebas de Validación

~Nombre completo (nombre)

Dato de prueba: "Lu"

Resultado esperado: El navegador bloquea el envío y muestra un aviso indicando que se requiere un mínimo de 3 caracteres (minlength="3").

Resultado obtenido: El navegador mostró el mensaje de validación y detuvo el envío.

~Número de documento (documento) — Longitud insuficiente

Dato de prueba: "12345"

Resultado esperado: El navegador bloquea el envío porque no cumple con el patrón de 6 a 10 dígitos numéricos (pattern="[0-9]{6,10}").

Resultado obtenido: El navegador detectó el error de longitud y bloqueó el formulario.

~Número de documento (documento) — Carácter inválido

Dato de prueba: "123456a"

Resultado esperado: El navegador bloquea el envío porque contiene una letra y el patrón solo permite números ([0-9]).

Resultado obtenido: El navegador rechazó el carácter no numérico y detuvo el envío.

~Correo electrónico (email)

Dato de prueba: "correosinarroba.com"

Resultado esperado: El navegador detecta que falta el símbolo @ y muestra un mensaje de formato de correo inválido (type="email").

Resultado obtenido: El navegador advirtió que el correo estaba incompleto y detuvo el envío.

~Celular (celular)

Dato de prueba: "4123456789"

Resultado esperado: El navegador bloquea el envío porque el patrón exige que el número empiece obligatoriamente por el dígito 3 (pattern="3[0-9]{9}").

Resultado obtenido: El navegador rechazó el dato por incumplir el inicio requerido y detuvo el envío.

~Fecha del alquiler (fecha)

Dato de prueba: "2026-10-31"

Resultado esperado: El navegador bloquea el envío por estar fuera del rango permitido, ya que el mínimo es el 2026-11-01 (min).

Resultado obtenido: El navegador indicó que la fecha es anterior al rango permitido y bloqueó el envío.

~Cantidad de bicicletas (cantidad)

Dato de prueba: 7

Resultado esperado: El navegador bloquea el envío porque el valor ingresado supera el límite máximo permitido de 6 (max="6").

Resultado obtenido: El navegador detectó que se superó el límite máximo y detuvo el envío.

~Políticas de alquiler (politicas_aceptadas)

Dato de prueba: [No marcado / Vacío]

Resultado esperado: El navegador impide enviar el formulario porque el checkbox de aceptación es obligatorio (required).

Resultado obtenido: El navegador señaló que es obligatorio aceptar las políticas para continuar.
